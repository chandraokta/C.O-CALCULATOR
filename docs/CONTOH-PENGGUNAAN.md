# C.O CALCULATOR SC-100 — Contoh Penggunaan Semua Fitur

Dokumen ini berisi contoh perhitungan untuk **setiap fitur** di aplikasi.
Urutan tombol ditulis dengan tanda `→`. Hasil memakai desimal koma (default).

> Tampilan utama memakai bahasa Inggris; menu **Pengaturan** memakai bahasa
> Indonesia. Panduan ini berbahasa Indonesia.

---

## 10. Konversi satuan

Buka dengan `SHIFT` `1` (tombol `CONV`).

| Kategori | Contoh |
|---|---|
| Length | `1` metre → **3,28084** foot |
| Mass | `1` kilogram → **2,20462** pound |
| Temperature | `100` Celsius → **212** Fahrenheit |
| Area | `1` square metre → **10,7639** square foot |
| Volume | `1` litre → **0,264172** US gallon |
| Speed | `100` km/h → **62,1371** mph |
| Time | `1` hour → **60** minute |
| Data | `1` megabyte → **1.000** kilobyte |
| Energy | `1` kilojoule → **0,239006** kilocalorie |
| Pressure | `1` bar → **14,5038** psi |

Cara pakai: pilih kategori, ketuk nama satuan **FROM**, ketuk nilai satuan **TO**,
lalu ketik nilai. Tombol `⇅` menukar arah konversi.

## Ringkasan cakupan fitur

- Empat operasi dasar, kurung, prioritas, perkalian implisit, tanda negatif
- Desimal koma/titik, grouping, EXP, AUTO/FIX/SCI/ENG
- Persen, pangkat, akar kuadrat/kubik, kuadrat/kubik, kebalikan
- Faktorial, nCr, nPr, modulus
- sin/cos/tan, arcsin/arccos/arctan, hiperbolik dan invers hiperbolik
- ln, log, eˣ, 10ˣ, π, e
- Memori utama dan sembilan slot, riwayat hasil
- Konverter 10 kategori dan 79 satuan, konstanta matematika/fisika
- Basis DEC/HEX/OCT/BIN
- Tema, sudut, format, digit, grouping, desimal, getar, suara, volume, keep awake
- Portrait dan landscape

Jika ada hasil yang tidak sesuai, sertakan urutan tombol dan hasil yang muncul saat
melaporkan masalah.
